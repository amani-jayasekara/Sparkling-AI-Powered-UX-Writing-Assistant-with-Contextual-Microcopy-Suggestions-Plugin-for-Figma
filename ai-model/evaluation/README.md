\# Sparkling Model Evaluation



The Sparkling model is evaluated as a generative UX microcopy model.



\## Metrics



\- Exact Match

\- ROUGE-L

\- Semantic Similarity



The final evaluation was performed using 144 unseen test records.



\## Final Fine-tuned Results



\- Exact Match: 33.33%

\- ROUGE-L: 58.83%

\- Semantic Similarity: 73.21%

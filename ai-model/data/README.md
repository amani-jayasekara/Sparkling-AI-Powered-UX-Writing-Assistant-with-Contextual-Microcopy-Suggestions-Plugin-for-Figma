\# Sparkling Dataset



This directory contains the datasets used for training, validation, and final evaluation of the Sparkling UX microcopy generation model.



\## Dataset Split



| File | Records | Purpose |

|---|---:|---|

| train.jsonl | 2,610 | Fine-tuning |

| validation.jsonl | 126 | Validation |

| test.jsonl | 144 | Final evaluation |



Each record contains UX context and the expected UX microcopy response.
